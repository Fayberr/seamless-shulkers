# Seamless Shulkers

A Fabric mod for Minecraft 26.3 that brings inventory-carried shulker boxes into everyday inventory workflows.

Development in progress. Features are not considered production-ready until CI and in-game testing pass.

## Target functionality

- Interactive 27-slot shulker preview (hold Alt to interact).
- Inventory refill from carried shulker boxes.
- Litematica Easy Place integration with configurable direct-use and refill modes.
- Villager trade replenishment when Space is used.
- Singleplayer and Fabric dedicated-server support with one JAR.
- Compatibility with Shulker Box Tooltip and optional Modern Config UI.

No third-party Shulker Box Tooltip source is copied. The project's license has not yet been selected by its owner.
